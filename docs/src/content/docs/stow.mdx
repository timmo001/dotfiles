Everything below is applied with `dot stow`. Dedicated pages cover [Hyprland](/hyprland/), [Ghostty](/ghostty/), [Herdr](/herdr/), [UWSM](/uwsm/), [Shell](/shell/), [OpenCode](/opencode/), [Pi](/pi/), and [Cursor](/cursor/). The rest stay as one-line blurbs.

| Package | Why it exists |
| --- | --- |
| `agents/` | Shared OpenCode assets; see [OpenCode](/opencode/) |
| `bash/`, `fish/`, `zsh/` | Shell config and `dot` completions |
| `cursor/` | Cursor launch helpers; agent notes on [Cursor](/cursor/) |
| `editorconfig/` | Shared editor formatting baseline |
| `fastfetch/` | System info display config |
| `hunk/` | Hunk tool config |
| `lazygit/` | Lazygit custom commands wired to `dot` git helpers |
| `mise/` | Global mise config for this machine class |
| `neovim/` | Editor config |
| `pi/` | Pi companion config; see [Pi](/pi/) |
| `plannotator/` | Shared plan/review annotation settings |
| `ripgrep/` | Default ripgrep flags |
| `scripts/` | `~/.local/bin` helpers used by the desktop and `dot` |
| `starship/` | Prompt config |
| `systemd/` | User units (timers and services) |
| `tmux/` | Terminal multiplexer fallback config |
| `topgrade/` | System update orchestration config |
| `yazi/` | File manager plugins and config |

Laptop-only overlays use the `--laptop` package suffix (`scripts--laptop`, `systemd--laptop`).
