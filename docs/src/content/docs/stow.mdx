---
title: Stow Packages
description: The few packages the cloud build keeps, and why it drops the rest.
---

A cloud session VM never runs `dot stow`, so this build drops the shell, editor, terminal and service packages the [server build](https://ubuntu-server.dotfiles.timmo.dev/stow/) stows. What's left is only what the build, tests and docs still read. See the [cloud overview](/cloud/overview/) for what a session gets instead.

| Package | Why it stays |
| --- | --- |
| `agents/` | Shared OpenCode assets, which the docs generators and tests read; see [OpenCode](/agents/opencode/overview/) |
| `dotfiles-skills/` | Global skills tied to these paths or private overlays, validated by lint; see [Skills](/agents/skills/) |
| `mise/` | Global [mise](https://mise.jdx.dev) config, read by the dependency tooling and its tests |
| `scripts/` | Untracked: where `dot` and `skill-maintenance` are built |
