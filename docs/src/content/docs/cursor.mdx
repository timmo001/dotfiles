---
title: Cursor
description: IDE-embedded coding agent and launchers.
---

Cursor’s agent runs inside the editor. It gets the mirrored global AGENTS instructions, not the full OpenCode plugin stack. The stow package also owns desktop launchers for the editor and agents windows.

| Piece | Why |
| --- | --- |
| Cursor agent | In-editor agent with mirrored AGENTS guidance |
| `dot agents-sync` | Keeps Cursor instruction files in sync with the OpenCode AGENTS source |
| `cursor-editor.desktop` | Launcher for the editor window |
| `cursor-agents.desktop` | Launcher for the agents window |
| `cursor/` stow package | Desktop entries and related defaults |

For slash commands, plugins, and Herdr-backed sessions, use [OpenCode](/opencode/).
