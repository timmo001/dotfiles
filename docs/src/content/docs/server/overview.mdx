The `distro/ubuntu-server` branch is a cut-down copy of the [Omarchy desktop](https://dotfiles.timmo.dev/) dotfiles for a headless [Ubuntu Server](https://ubuntu.com/server) machine. It keeps the terminal and service tooling, drops everything that needs a graphical session, and hosts a [Herdr](/server/herdr/) session that other machines attach to.

| Kept | Why |
| --- | --- |
| Shell and terminal tools | zsh, Starship, tmux, Neovim, Yazi, Lazygit, btop and fastfetch work the same over SSH |
| `dot` and mise | Same CLI and toolchain as the desktop, so shared changes merge across |
| Agents | OpenCode, Pi and the shared skills |
| Herdr | Runs as a user service for remote clients |
| User services | Headless timers and daemons, such as dependency updates |

| Dropped | Why |
| --- | --- |
| Hyprland, UWSM, Ghostty, Omarchy Shell | No graphical session |
| Cursor and browser helpers | No desktop apps or browser |
| pacman and AUR packages | Ubuntu uses apt; the package list is rewritten with apt names |

## Still open

`dot` has its desktop code removed: packages install with apt, `dot up` runs apt, release packages and compose up, and failures go to the journal. [Changes from the desktop](/server/changes/) lists every file this branch removes or changes.

Open server work is tracked in [GitHub issues](https://github.com/timmo001/dotfiles/issues).

:::caution[Personal setup]
This build is tuned for one machine and a private overlay that is not public. Borrow the pieces you want rather than installing it wholesale.
:::
