[OpenCode](https://opencode.ai) is the main interactive agent UI: sessions, slash commands, plugins, and Herdr panes. Most agent work happens here.

| Piece | Why |
| --- | --- |
| `agents/.config/opencode/` | Agents, commands, plugins, and shared `lib/` |
| `agents/.agents/skills/` | Pinned [`timmo001/skills`](https://github.com/timmo001/skills) checkout |
| [`opencode-config`](https://github.com/timmo001/opencode-config) | Portable publish of the same assets |
| `dot mcp-sync` | MCP servers from private `mcp.yml` |
| `dot agents-sync` | Mirrors global AGENTS into other harnesses |

| Layer | Role |
| --- | --- |
| Agents | Execution posture (permissions, tools, plan mode) |
| Commands | Thin routers to agents and skills |
| Skills | Reusable workflows |
| Plugins | Context injection and enforcement hooks |
