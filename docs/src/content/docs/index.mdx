The cloud build of my dotfiles, for agent sessions that run in a short-lived cloud VM rather than on one of my machines. It starts with [Claude Code cloud sessions](https://code.claude.com/docs/en/claude-code-on-the-web). It is the [Ubuntu server](https://ubuntu-server.dotfiles.timmo.dev/) build cut down to what a session uses: the compiled `dot` CLI, its pinned toolchain, my Claude Code settings and instructions, and the shared skills. Nothing is stowed and no services run.

```bash
# The cloud environment's setup script
curl -fsSL https://raw.githubusercontent.com/timmo001/dotfiles/distro/cloud/cloud/setup.sh | bash
```

:::caution[Personal setup]
These docs and the public dotfiles are for reference. They are tuned for my own cloud environment and a private overlay that is not public, so pointing your setup script at them is not recommended. Have your agents borrow the ideas you want instead.
:::

## How a session gets set up

| Stage | What happens |
| --- | --- |
| Setup script | Runs once per environment: clones this branch, installs mise and the toolchain, builds `dot` and runs `dot cloud setup`. The environment snapshots the result |
| Session start | A Claude Code hook pulls the latest branch, clones the private overlay and adds the global agent instructions |
| Session | `dot`, `mise`, the skills and the instructions are ready; repositories attached to the session are cloned under `/home/user` |
