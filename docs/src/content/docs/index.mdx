# Dotfiles

Personal [Omarchy](https://omarchy.org) dotfiles (Arch-based), managed with [GNU Stow](https://www.gnu.org/software/stow/) and a compiled `dot` CLI. Public config, desktop customisations, git tooling, and a shared OpenCode setup. Private machine details live in a separate overlay.

:::caution[Personal setup]
These are tuned for my machines and a private overlay that is not public. Borrow ideas; do not install wholesale.
:::

## Parts

| Area | Why it exists |
| --- | --- |
| [Getting started](/getting-started/) | How I bootstrap a fresh Omarchy machine |
| [Configuration](/configuration/) | Private overlay, packages, and tracked app config |
| [`dot` CLI](/dot/) | One binary for init, update, stow, doctor, and day-to-day tooling |
| [Git & GitHub](/git/) | Cross-repo status, commits, and notifications without juggling many checkouts by hand |
| [Omarchy & Hyprland](/omarchy/) | Desktop and host overrides on top of Omarchy Quattro |
| [OpenCode & Agents](/opencode/) | Shared agents, commands, skills, and plugins (also published as [`opencode-config`](https://github.com/timmo001/opencode-config)) |

Generated catalogues live under Reference. Machine-readable bundles and the docs MCP are on [Agents / LLMs](/agents-llms/).
