My [Omarchy](https://omarchy.org) dotfiles (Arch-based). [GNU Stow](https://www.gnu.org/software/stow/) links each package into place, and a compiled `dot` CLI sets up, updates and checks each machine. It covers public config, desktop customisations, git tooling and a shared [OpenCode](https://opencode.ai) setup. Private machine details live in a separate overlay.

```bash
# Pull, refresh config, re-stow and rebuild
dot update

# Run the health checks and save a report
dot doctor
```

:::caution[Personal setup]
These docs and the public dotfiles are for reference. They are tuned for my machines and a private overlay that is not public, so installation is not recommended; borrow ideas rather than installing wholesale.
:::
