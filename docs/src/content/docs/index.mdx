The headless [Ubuntu Server](https://ubuntu.com/server) build of my dotfiles. It is a cut-down copy of the [Omarchy desktop](https://dotfiles.timmo.dev/) setup with the terminal and service tooling only, and it hosts a [Herdr](/server/herdr/) session that other machines attach to. [GNU Stow](https://www.gnu.org/software/stow/) links each package into place, and a compiled `dot` CLI sets up, updates and checks the machine. Private machine details live in a separate overlay.

:::tip[Cloud build]
This is the cloud build: the server build described below, with a layer for Claude Code cloud sessions. See the [cloud overview](/cloud/overview/).
:::

:::note[Work in progress]
This build is ahead of the real server. See the [server overview](/server/overview/) for what is still open.
:::

```bash
# Pull, refresh config, re-stow and rebuild
dot update

# Run the health checks and save a report
dot doctor
```

:::caution[Personal setup]
These docs and the public dotfiles are for reference. They are tuned for my machines and a private overlay that is not public, so installation is not recommended. Have your agents borrow the ideas you want instead.
:::
