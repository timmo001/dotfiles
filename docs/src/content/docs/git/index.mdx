`dot` includes a suite of git and GitHub tools that work across every managed repo (public and private dotfiles, configured private git repos, and Omarchy repos). Most have an interactive TUI plus `--raw` and `--bar-json` output for scripts and status bars.

## Status bar integration

Several of these commands emit `--bar-json` output for a status bar module. See [Bar Integrations](/git/bar-integrations/) for the JSON format, click actions, and which commands support it.

## Private repo configuration

Repo activity, workflow, and notification settings live in the private `dot-git.yml` config. See [Private Git Config](/configuration/private-git/) for the schema.
