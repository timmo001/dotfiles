title: Hyprland
description: Stowed Hyprland config and per-host overrides.
---

Window manager config for this Omarchy setup. It is a stowed `hypr/` package, not a forked Omarchy Hypr repository. `dot stow` lays it down with `--no-folding`, keeps the host symlink repaired, and reloads Hyprland afterwards without dropping the live config mid-stow.

| Piece | Why |
| --- | --- |
| Shared Lua entry files | Bindings, input, monitors, look-and-feel, autostart |
| `hosts/desktop`, `hosts/laptop` | Machine-specific overrides |
| `~/.config/hypr/host` | Runtime symlink to `hosts/$OMARCHY_HOST` |
| `bin/` | Small Hypr helpers on `PATH` via [UWSM](/uwsm/) |
| `float-app.lua` | Shared floating rules from float-app |

Bindings and layout scripts stay in the package; they are not listed here.
