---
title: Herdr
description: Shared agent terminal multiplexer config.
---

Herdr is the shared terminal multiplexer for coding agents. One server session, many Ghostty clients. Config is stowed from `herdr/` into the runtime-owned `~/.config/herdr/` directory (logs and sockets stay untracked there).

| Piece | Why |
| --- | --- |
| `config.toml` | Prefix keys, tab/workspace behaviour, plugin commands |
| Stowed plugins | Local helpers (repository picker, terminal title, Yazi, mise tasks, Plannotator) |
| Herdr Lazy | Plugin lockfile restored on `dot update` |
| OpenCode integration | Agent panes and prompts inside Herdr |

`dot update` restores the Lazy lockfile and local plugins. `dot doctor` warns when Herdr or the OpenCode integration is missing and prints the repair command.
