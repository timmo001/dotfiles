[Claude Code](/claude/overview/) is the harness a cloud session runs. Shared skills live in a separate repo: `dot` keeps a checkout at `~/.local/share/dot/skills`, detached at the latest `main`, and links it into `~/.agents/skills/` and `~/.claude/skills/`. The [OpenCode](/agents/opencode/overview/) config is still published from this repo, though a session doesn't run OpenCode.

| Piece | Why |
| --- | --- |
| [Claude Code](/claude/overview/) | Settings, instructions, skills and the session start hook |
| [Skills](/agents/skills/) | Shared catalogue plus repo-local skills |
| [OpenCode](/agents/opencode/overview/) | Published OpenCode agents, commands and plugins |
