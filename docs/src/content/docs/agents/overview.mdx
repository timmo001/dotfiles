Coding agents in this setup share skills and AGENTS guidance. [OpenCode](https://opencode.ai) is the primary harness; Pi is a thinner companion. Shared skills live in a separate repo. `dot` keeps a checkout detached at the latest `main` and links it into `~/.agents/skills/`.

| Piece | Why |
| --- | --- |
| [Skills](/agents/skills/) | Shared catalogue plus repo-local skills |
| [OpenCode](/agents/opencode/overview/) | Day-to-day sessions, slash commands, plugins, Herdr panes |
| [Pi](/agents/pi/) | Lightweight companion sessions |

## Shared wiring

| Mechanism | Role |
| --- | --- |
| `dot agent sync` | Mirror global AGENTS into other harness instruction files |
| `dot mcp sync` | Regenerate MCP configs from the private overlay; OpenCode repos opt in per checkout |
| `dot skills` | Check and apply updates from the skills repo |
| `~/.agents/skills/` | Shared skills linked from the latest skills repo `main` |

OpenCode owns the full agent, command, and plugin stack. Pi reuses skills and AGENTS, not that stack.
