---
title: The dot Command
description: The CLI that drives the dotfiles system.
---

`dot` is the compiled CLI for these dotfiles ([Bun](https://bun.sh) + [Effect](https://effect.website) v4), stowed to `~/.local/bin/dot`. It owns setup, sync, stow, health checks, and the git helpers used day to day.

| Command | Purpose |
| --- | --- |
| `dot init` | First-use setup on a fresh machine |
| `dot update` | Pull, refresh config, stow, rebuild |
| `dot stow` | Stow only |
| `dot doctor` | Health checks |
| `dot git-diff` | Change state across managed repos |
| `dot git-commit` | Guarded commit gateway |

Full flags and subcommands: [Command Reference](/dot/commands/) (generated from `dot/src/cli/spec.ts`) or `dot --help`.
