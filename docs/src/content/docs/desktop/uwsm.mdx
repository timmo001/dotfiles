---
title: UWSM
description: User environment overrides for the graphical session.
---

[UWSM](https://github.com/Vladimir-csp/uwsm) starts the graphical session. [Omarchy](https://omarchy.org) Quattro owns the defaults under `/usr/share`. This repo only layers the user values these dotfiles need.

| Piece | Why |
| --- | --- |
| `uwsm/.config/uwsm/env.d/90-dotfiles` | User env fragment applied on session start |
| Hypr `bin` on `PATH` | Makes stowed Hypr helpers available to UWSM apps |
| Other env exports | Session values required by desktop scripts and terminals |

`dot stow` removes the retired `timmo001/omarchy-uwsm` checkout before this package takes ownership. Changes need a [Hyprland](https://hyprland.org) relaunch to take effect.
