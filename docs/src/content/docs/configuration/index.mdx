Most behaviour is controlled by explicit CLI flags. Runtime configuration is done with environment variables for process context, and a private YAML file for git/GitHub repo tracking.

<CardGrid>
  <LinkCard title="Environment Variables" href="/configuration/environment/" description="All DOT_*, DOTFILES_*, and OMARCHY_* options." />
  <LinkCard title="Private Git Config" href="/configuration/private-git/" description="The dot-git.yml schema for repo activity, workflows, and notifications." />
</CardGrid>

:::note[Configuration policy]
For dotfiles and system scripts, prefer explicit CLI flags over environment-variable toggles for runtime behaviour. Environment variables are used for standard process context (`HOME`, `PATH`, `XDG_*`), secrets, paths, and compatibility shims.
:::
